# Avatar style sample prompts

> **Now in admin:** admin → Avatar sheets → "AI prompts" on each style has the up-to-date girl and boy prompts (with plotter spacing) and Copy buttons. This file is the older draft.

Prompts for making sample sheets for each avatar style in your AI image tool (ChatGPT, Gemini, etc.). Each style needs two sheets, one girl and one boy, like the 90s Retro and Anime samples.

**How to use**

1. Paste the **base prompt**, then the **style line**, then "girl" or "boy".
2. Generate in portrait (A4 / 2:3).
3. Save the PNG to Downloads and send it here. I'll convert it, crop the card picture and add it.

Use original characters only. No famous anime, cartoon or movie characters, and no real celebrities.

## Base prompt (same for every style)

> A4 portrait sticker sheet on a pure white background. At the top, a bold die-cut sticker title logo reading "{STYLE NAME}" in a matching style. Below it, a 3×3 grid of 9 die-cut stickers of the SAME original young {girl/boy} character, each with a thick white sticker border and a soft shadow, even gaps between stickers. Each sticker shows a different pose and expression: peace sign, wink, big laugh, thumbs up, hand on cheek, pointing at viewer, headphones on, holding a drink, shy smile. Small decorations around each one (hearts, stars, sparkles, music notes). Bright, clean, high detail, print-ready. Original character, not based on any existing character or real person. No other text.

Each sticker shows a different pose and expression: peace sign, wink, big laugh, thumbs up, hand on cheek, pointing at viewer, headphones on, holding a drink, shy smile.
